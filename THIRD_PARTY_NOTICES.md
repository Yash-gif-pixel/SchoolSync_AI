## Flutter Dashboard Template

The application's visual design — the navigation rail and header shell, the
card grid, the tinted icon tiles and the stat tiles — is adapted from the
Flutter Dashboard Template by Hany Sameh.

Adapted rather than copied: the original is a dark stock-trading dashboard
whose widgets are hardcoded to market data and sized as fractions of the
viewport. This project reimplements the same visual language on a light
palette, with fixed spacing and real layout constraints, against its own data.
